# OIBSIP-Data_Analysis
Oasis Infobyte data analysis

### Task1 Level1- Exploratory Data Analysis on Retail Sales Data
This task performs an exploratory data analysis on the retail sales data set from kaggle.com to uncover patterns and trends within the data and give out an insightful business recommendation.

The analysis covers descriptive stats to understand the retail store's demographics. Time series analysis for yearly customer engagement with the store, and customer demographic analysis.

### Task2 Level1- Customer Segmentation Analysis
This task covers RFM analysis and K-means clustering algorithm. The goal of the project is to categorise a company's customer base and give a business driven solution.

### Task1 Level2- Predicting House Prices With Linear Regression
The task covers regression analysis, however, since we used a synthetic data set, our linear relationship was negligible.
